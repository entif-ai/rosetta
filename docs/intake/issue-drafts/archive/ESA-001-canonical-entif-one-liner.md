## Summary

Adopt the canonical one-liner synthesized across 12+ source documents: "Entif is a governed, local-first cognition OS whose entire job is to turn messy reality into auditable, content-addressed meaning and then (optionally) into constrained action, with Rosetta as the semantic spine and Tiles as the portable knowledge substrate."

## Rationale

This one-liner emerged from a forced synthesis of 12+ disparate source documents including Entif v0 Bootstrapping Plan, Rosetta v3 Core Spine Specification, Cognitive Tiles and Swarm Gnosis, SAFE documentation, and Crates Media blueprints. It is the most concise distillation of the project's core identity and purpose.

The one-liner succeeds because it simultaneously:
- Defines the operating mode (governed, local-first)
- States the primary function (turn reality into auditable, content-addressed meaning)
- Identifies the action layer (constrained action, optional)
- Locates the technical substrate (Rosetta = semantic spine; Tiles = portable knowledge)

## Recommended Action

1. Add to Entif v0 documentation as the canonical positioning statement
2. Use in all external-facing communications (README, pitch decks, marketing)
3. Align Rosetta Bootstrap and NOT LAME PRD to this framing
4. Ensure all subsequent architectural work traces back to this one-liner
