# CTS-009: ZKP-Signed EvidenceBundles with Optical Refs + Provenance Integration

## Type
`implementation`

## Labels
`provenance-forge`, `zk-proofs`, `evidencebundle`, `optical-evidence`

## Depends On
`SemanticCodecForge, ProvenanceForge`

## Evidence
PRD Section 2.6: "A ZKP generated by ProvenanceForge can attest: 'I, Agent A, using certified Decompressor Model B, derived Text C from Image D.' This is a cryptographically secure, yet extremely compact, form of evidence."

PRD Section 2.3.2: "When a decision is made based on a document, the EvidenceBundle can now include the compressed image (or its content hash from FileForge) instead of the full text."

PRD: "Every Receipt now has a new field: slug_refs: SlugURI[]. Every action is explicitly linked to the compressed knowledge it used."

## Problem Statement
ProvenanceForge needs ZKP-signed EvidenceBundles that can cryptographically attest to the derivation chain of optical decompression, enabling compact yet irrefutable audit trails where evidence is the compressed image (or its hash) rather than the full decompressed text.

## Scope

### Must Include
- [ ] ZKP schema for optical derivation attestation: prover (Agent A), model (Decompressor B), input (Image D), output (Text C)
- [ ] ZKP generation on optical decode completion
- [ ] EvidenceBundle update: include compressed image OR content hash (not full text)
- [ ] Receipt.slug_refs field: array of SlugURI linking receipts to compressed knowledge used
- [ ] Provenance attestation API
- [ ] Verify ZKP attestation without revealing full content
- [ ] Chained receipt integration: final receipt links all prior parsing receipts

### Should Include
- [ ] ZKP verification service (lightweight verification endpoint)
- [ ] Compressed image storage optimization (store once, reference by hash)
- [ ] EvidenceBundle audit trail UI

### Could Include
- [ ] Cross-agent ZKP attestation (Agent A → Agent B handoff with preserved provenance)
- [ ] Time-bounded ZKP validity (expire old proofs)

## Acceptance Criteria
- [ ] ZKP attestation generated for every optical decode operation
- [ ] EvidenceBundle includes compressed image or hash (not full text)
- [ ] ZKP verifies correctly: attestation confirms Agent A used Model B to derive Text C from Image D
- [ ] Receipt.slug_refs populated on all knowledge-linked actions
- [ ] Receipt chaining audit trail complete and verifiable

## Notes
ProvenanceForge is referenced in multiple other specs (NOT LAME PRD, Entif 2.0). Coordinate with existing ProvenanceForge implementation to avoid duplication.
