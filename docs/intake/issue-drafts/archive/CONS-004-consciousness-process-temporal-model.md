# CONS-004: Consciousness as Process, Not State — Temporal Model for Entif

**Status:** issue-candidate (not yet filed as GitHub issue)
**Labels:** `consciousness`, `process`, `temporal`, `dynamics`, `non-collapse`
**Depends on:** MHC-003-non-collapse-contract

## Problem Statement

Entif currently models consciousness as a property or state. The "process of consciousness" framing suggests it is a continuous, boundary-less flow. Without a temporal model, Entif cannot represent its own consciousness as something that unfolds over time — only as something that exists or doesn't.

## Specific Findings

- **F-CONS-007** (confidence: high): Consciousness as process vs. state — continuous, evolving, no sharp boundary
- **F-SYN-003** (from mHCs-engram extraction): Non-collapse contract prevents collapsing ambiguity to singletons

## Action Required

1. Define temporal model: continuous event-based, phase-based, or hybrid?
2. Define consciousness mode transitions: passive monitoring ↔ active reasoning ↔ resting — what triggers each
3. Integrate non-collapse contract: ambiguity flows through temporal model without collapsing to a singleton
4. Define self-observation in process model: meta-cognitive loop — how Entif observes its own consciousness process
5. Define "resting" or "passive" consciousness: background processing during heartbeat vs. active tile processing
6. Define process boundaries: what constitutes the start/end of a consciousness episode — or is it boundary-less?
