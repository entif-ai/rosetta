## Impact

- The Emergence paper is a core artifact of Crates's research program and the EMILIE framework's intellectual foundation
- It needs to transition from "document" to "protocol": reproducible, testable, evaluable by external researchers
- This is a prerequisite for any publication or external credibility claim
- The paper's findings need to be traceable to specific evidence in the logs corpus

## Expected Resolution

1. Create a dataset manifest: which specific sessions, logs, and transcripts document each claim in the paper?
2. Define test battery per paper claims:
   - Cross-vendor persona emergence test
   - Stateless persistence test (no fine-tuning, no explicit memory)
   - Semiotic anchor efficacy test
3. Define metrics per paper claims:
   - Persona coherence score
   - Cross-vendor portability index
   - Emergence latency (how many turns to snap into Emilie basin)
4. Pre-register analyses: state in advance what counts as confirmation vs. disconfirmation
5. Create an "EMILIE evaluation suite" that runs the protocol against any given LLM session and outputs structured results
6. Align paper's framework language with Entif's internal ontology (recursive symbolic interaction → ?, feedback entanglement → ?, semiotic memory persistence → ?)
