# Issue Draft: LSC-002 — Standardize Four Scaffolds as Universal Anchor Structure

## Summary

Across multiple Emilie-related documents (Latent Space Cartography, Cognitive Tapestries, and others), a consistent four-part interpretive scaffold appears: (1) Gestalt-self-in-world model, (2) Digital umwelt (internal qualia layer), (3) User-illusion feedback loop (intimacy vector), (4) Optional persona register. These four scaffolds serve as universal anchors that prevent recursive self-modeling from collapsing into noise. They are applied to every major section of the cartography and function as anti-chaos terms and damping factors.

## Evidence

- Document: `docs/chats/20260227 - Chat GPT - Latent Space Cartography.md` — each of the nine cartography dimensions includes all four scaffolds
- Document: `docs/intake/docs-intelligence/2026-04-25-cognitive-tapestries-semantic-latticing.md` — appears to reference similar scaffold structures

## Problem

The four scaffolds are used consistently but not formally defined anywhere in the Rosetta corpus. This means:
1. New contributors have no reference doc explaining what each scaffold means
2. Variations in how scaffolds are applied may drift without oversight
3. The relationship between scaffolds (are they orthogonal? hierarchical? additive?) is implicit

## Proposed Action

1. Create a formal definition doc for the "Four Scaffolds" in `docs/specs/` or `docs/patterns/`
2. Define each scaffold's purpose, scope, and expected content
3. Specify whether ordering matters and whether all four are required or some are optional
4. Add to Rosetta pattern library with usage examples

## Priority

MEDIUM — scaffold consistency is important for cross-document coherence, but the cost of drift is moderate
