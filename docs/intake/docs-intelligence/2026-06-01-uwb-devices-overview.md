## Components And Technologies

- **UWB ranging radio** (IEEE 802.15.4a/4z, FiRa/CCC ecosystem) — consumer device positioning
- **UWB radar / impulse sensing** — specialized hardware (Detex, DepLife, Camero Xaver, ReTwis); not consumer phone UWB
- **WiFi CSI (Channel State Information)** — phase+amplitude across subcarriers; richer than RSSI; requires infrastructure access
- **WiFi RTT (Round-Trip Time)** — time-based WiFi ranging where supported (IEEE 802.11mc)
- **BLE proximity** — coarse presence/clustering signal, weak geometric constraint
- **Anchor time pilots** — anchors emit known acoustic or RF pilot sequences for per-device clock calibration
- **Factor graph estimator** — robust optimization with Huber/Cauchy losses, NLoS detection, iSAM2-style incremental smoothing
- **SensoryForge** — ephemeral feature extraction module; RAM-only ring buffer; no raw stream persistence by default
- **Venue State Vector (VSV)** — compressed output format: occupancy grid + flow field + tracked entities + event map + health metrics
- **SSIE (Sealed Spatial Incident Envelope)** — `sdf.ssie.v1` JSON schema for quorum-gated spatial threat disclosure
- **Guardian Mode** — SDF operational mode for threat scanning with Tripwire integration
- **CMU DensePose From WiFi** — learned CSI-to-pose mapping; requires 3×3 MIMO, 100Hz, 30 subcarriers; degrades on unseen layouts and with 3+ subjects

## Conceptual Claims

- **Crowd-SLAM**: Dense swarm of partially-instrumented humans + factor-graph estimator = moving sensor array producing emergent spatial map
- **Phones-as-tags vs phones-as-imagers**: Consumer phones can serve as cooperative ranging tags providing constraint density; they cannot replace radar-grade infrastructure sensors without OS-level CSI/CIR exposure
- **Clock sync via latent estimation**: Per-device offset, drift, and pipeline latency are estimated continuously as hidden variables, not assumed synchronized
- **N-device redundancy**: sqrt(N) error reduction for independent errors; does not fix correlated multipath bias; enables viewpoint diversity for NLoS rejection
- **Anchored mapping required**: Without surveyed anchor spine, spatial map "floats" (arbitrary rotation/translation/scale); crowd density reduces anchor count needed, not anchor necessity
- **Anti-Panopticon / Blind Watchman**: The system knows *what is happening* without storing *who did it*; ephemeral by default; quorum-gated minimal disclosure
- **Guardian Mode as Tripwire extension**: Spatial threat detection extends semantic Tripwire Protocol with physical telemetry; same governance primitives apply
- **SDF as compressed venue state**: VSV (occupancy + flow + events + health) is the wire format; compressed far below raw sensor bandwidth
- **Hybrid sensing beats any single modality**: Cameras for visual detail; RF (UWB/WiFi) for occlusion resistance and robustness; microphones for sound source localization; inertial for dead reckoning

## Dependencies And Sequencing

- SDF Guardian Mode depends on: (1) Tripwire Protocol already being implemented; (2) Rosetta sealed incident tiles existing; (3) anchor deployment capability for venue
