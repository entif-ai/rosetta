## Components And Technologies

- **AttnRes** (Kimi/Moonshot, arXiv 2603.15031): depth-wise softmax attention over prior layer outputs; Block AttnRes groups layers into blocks; zero-initialized pseudo-query vectors; RMSNorm on K/V; two-phase inference
- **DeepCrossAttention** (DCA, arXiv 2502.06785v2): prior art in same family; GRN-v1/v2/v3; more general; less scale-focused
- **CCA / CCGQA** (arXiv 2510.04476): compressed convolutional attention; down-projects Q/K/V into compressed latent; conv mixing on compressed Q/K; q-k-mean; value-shift; fused kernels for production efficiency
- **Draft-and-Prune** (arXiv 2603.17233, zyni2001/draft-and-prune): draft → formalize → repair → execute → prune → aggregate; pruning lifts AR-LSAT accuracy 45%→78%; lacks equivalence-aware aggregation
- **H-Neurons** (arXiv 2512.01797v2): <0.1% FFN neurons predict hallucination via over-compliance tendency; pretraining-originated; instruction-tuning-preserved
- **Ng article** (dnhkng.github.io/posts/rys/): middle-layer reuse hypothesis; Base64 observation; format-agnostic reasoning middle; not peer-reviewed
- **New Ithkuil**: grammar/manual as curriculum scaffold; 570-page lexicon; 6000+ roots; official texts; community translations

## Conceptual Claims

1. **Two-axis architecture**: AttnRes/CCA hybrid = depth routing (which earlier states matter) + in-layer token mixing (what happens inside remembering); these are separate mechanisms attacking different bottlenecks and compose cleanly.
2. **Rosetta tiles as semantic OS before native alphabet**: bundles/tiles/tapestries become operational lingua franca before pasigraphy becomes tokenizer-native; Phase A/B build external substrate, Phase C adds adapters, Phase D considers deeper pretraining.
3. **Draft-and-Prune + H-Neurons + Rosetta = complete control loop**: D&P provides external verification (well-definedness, satisfiability), H-Neurons provides internal risk sensing (over-compliance), Rosetta provides canonical object space for equivalence-aware aggregation that D&P explicitly lacks.
4. **AttnRes does not replace transformer backbone costs**: it only changes residual/depth-mixing mechanism; the backbone's own attention/MoE/MLP costs remain; AttnRes is a quality-per-compute advantage, not a literal per-run speedup coupon.
5. **Semantic slugs and attention optimizations are complementary**: slugs reduce bytes entering context; attention optimizations reduce cost of moving bytes inside machinery; pursuing both in parallel yields compounding efficiency gains.
6. **Ithkuil as tutor, not monarch**: curriculum scaffold and compositional ordering, not sovereign ontology; prevents Rosetta from kneeling before any single external system.
7. **High semantic leverage concepts > common words for SeedPack**: first tiles prioritize entity/agent, action/event, time/causality, identity/location, request/permission/obligation, uncertainty/ambiguity/evidence.
8. **Self-enrichment must be human-reviewable and evidence-bound**: prevents elegant ontology drift factory; governance gate required for all self-proposed expansions.
9. **Hallucination ≠ reasoning error**: H-Neurons shows hallucination partly baked into pretraining over-compliance; Rosetta reduces inexplicable hallucinations but wrong answers (from bad reasoning) remain distinct and require different fixes.

## Contradictions Or Supersession

- **Ng article vs Rosetta project**: Ng hypothesizes latent format-agnostic middle in transformers but provides no actionable mechanism; Rosetta project explicitly aims to make that middle legible, typed, auditable — not to discover it, but to externalize and control it. This is complementary, not contradictory.
- **"Train AttnRes via LoRA" vs this doc**: earlier thoughts may have assumed LoRA for AttnRes retrofit; this doc corrects: pseudo-query vectors are standalone parameters too small for LoRA utility, train directly with RMSNorms; PEFT modules_to_save does not cover standalone parameter vectors.
- **"CCA retrofit with conv-only LoRA" vs this doc**: earlier approach of training only new conv layers is insufficient; the compressed Q/K/V/O projection path must also exist and be trainable for CCA to work properly.
