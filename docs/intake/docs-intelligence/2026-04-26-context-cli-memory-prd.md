## Summary

This PRD defines the Entif SDK CLI and Service Platform as a receipt-bound, source-aware, rights-scoped cognitive operating layer built above Rosetta's constitutional substrate. Key contributions: formalizes the assimilation packet as a first-class artifact, specifies three memory planes (truth/provenance, temporal, activation), defines multi-axis evaluation vectors with decision-specific reducers (rejecting scalar collapse), establishes the CLI as a primary operator bootstrap surface with three modes and explicit intake/memory/context commands, specifies a TypeScript SDK with eight typed modules, defines a dual OpenAPI 3.1.1 + AsyncAPI 3.1.0 service contract surface, and sequences five-phase delivery from constitutional hardening through docs intelligence. The PRD also explicitly enumerates non-goals (no mutable single store, no retrieval-before-authz, no vector-only memory, no scalar collapse of multi-dimensional signals).

---

## Goals And Intent

- Hardening of Rosetta constitutional substrate as a prerequisite
- Finish real boundary contracts before layering SDK, CLI, and service APIs
- Build Live adapters, memory planes, and operator surfaces in strict phased order
- Ensure every cognitively meaningful event emits or is provably bound into a receipt
- Make selective context injection a first-class compile step, not a prompt-building afterthought
- Ensure the platform can at any time answer: what was observed, inferred, promoted, evidenced, contradicted, rights-scoped, policy-governed, and projected

## Conceptual Claims

1. Ingester = compiler pipeline, not brain or memory soup; produces typed artifacts, receipts, projections, and retrieval-ready bundles
2. Assimilation packet is the canonical boundary object between intake and all downstream memory/write/correlation work
3. Three-plane memory model (truth/provenance, temporal, activation) prevents long-lived truth corruption by short-lived relevance
4. Multi-axis evaluation vectors with decision-specific reducers replace scalar ranking
5. No delete primitive on truth/provenance plane; wrongness represented as new provenance-bearing state
6. Context compilation is a first-class compile step producing an artifact with its own identity, receipt, and English accompaniment
7. Subcalls must return bounded symbols or artifacts; re-injection into parent context requires policy+receipt controls
8. Source registry separates platform-level facts from record-level facts; late identity resolution is evidence-producing and receipted
9. Four distinct dedupe types: byte-identical, manifestation-equivalent, clustered semantic near-duplicates, true revisions/supersessions
10. Every cognitively meaningful event must emit or be provably bound into a receipt
11. Rights scoping at storage/boundary layer, not post-retrieval filter
12. Five-phase delivery: constitutional hardening → text-core completion → live adapter introduction → memory-plane expansion → docs intelligence
13. Rosetta is the stable constitutional kernel; Entif is the operating layer — they must not collapse into one
14. Downstream stores (projections, graph views, conversational-memory adapters) are never canonical; canonical hierarchy enforced
