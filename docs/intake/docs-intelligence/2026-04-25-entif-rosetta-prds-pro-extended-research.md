## Conceptual Claims

- **Rosetta as constitutional substrate**: Rosetta is the stable semantic spine, not decorative metadata. The minimal operational spine (Run → Action → ToolCall → Observation → Evaluation → Receipt) is load-bearing, not ornamental. Raw signals must remain distinct from later interpretations; conjecture/uncertainty must not be silently collapsed.
- **Receipts as evidence currency**: Every meaningful ingestion, extraction, routing, transformation, policy decision, promotion, retrieval, execution, verification, or replay step emits machine-usable receipts. Logging alone is insufficient. Receipts are core operational evidence, not optional garnish.
- **Ingress Refinery as Pillar Zero**: Cost control, deduplication, provenance, rights, and semantic escalation decisions must happen before anything enters memory or orchestration. This is the load-bearing compression and adjudication layer.
- **Context = Tapestry, Not Prompt Dump**: Agents and workers receive bounded, provenance-complete, rights-scoped compiled context packages. Raw context flooding is never the default operating mode.
- **Rights at ingest, enforced throughout**: Rights, tenancy, sensitivity, and consumer scope attach at ingest and are enforced through indexing, retrieval, promotion, caching, and context compilation. Never retrieve-first-filter-later.
- **Guard as exclusive PEP**: All side-effecting operations pass through a deny-by-default policy enforcement point / guard layer. Parse-only default for ambient or untrusted ingest. Dry-run first where practical.
- **TDD-first + backlog-as-tests**: Major modules defined first by tests and contracts. Positive-frame and negative-frame tests both required. Unfinished work = pending/failing tests, typed stubs, acceptance-defined tickets, ADRs — not vague future prose.
- **TypeScript-first, Python-where-justified**: TS is the default implementation spine; Python is allowed/expected only for isolated specialist modules where it materially improves implementation quality or leverage. The core spine stays in TS.
- **Nx IS the workspace model**: Not just a build tool — Nx's project graph, affected execution, remote caching, generators, and cloud integration are load-bearing structural decisions, not conveniences.
- **Solo-builder realism**: One capable builder + LLM assistance. Every design must pass the "can one person scaffold this quickly with LLM help?" test. Prefer minimum powerful abstraction, thin vertical slices, interfaces reserved now over overbuilding now.
- **ACP = edge adapter only**: ACP/ACPX-like protocols are good for edge interoperability but are NOT the constitutional center. Core runtime = Rosetta + Guard + receipts, not ACP/ACPX.
