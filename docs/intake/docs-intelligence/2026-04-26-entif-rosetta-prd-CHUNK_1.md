## Conceptual Claims

1. **Rosetta ≠ Entif**: Rosetta is the minimal immutable content-addressed constitution; Entif is the governed execution/memory/orchestration layer that uses Rosetta as its source of truth. These are distinct and must not be conflated.
2. **Bootstrap headless but mechanics real**: Fixture-backed packages have real cryptographic/structural mechanics; the distinction between "real internals" and "fixture upstream" is the implementation leverage point.
3. **Docs intelligence is a planning lane, not runtime ingestion**: Requirements mining is allowed now; Rosetta-native semantic corpus ingest is blocked until Ingress Refinery + canonical cache are durable.
4. **No single master score**: Trust, relevance, urgency, novelty, contradiction pressure, decay are not substitutable currencies. Gate-first, ranking-second with lane-local dominance rules.
5. **Source is not a monolith**: Source-system profile, record, manifestation, package, identity evidence, correction, and trust are linked but distinct facts.
6. **Three memory planes are architectural law**: Truth (immutable), temporal (historical), activation (recency/frequency) must never collapse into one store.
7. **Projection shells are never authorities**: OB1, Prism, Mission Control are read-only views subordinate to Rosetta constitutional center.
8. **Rights enforcement at boundary, not post-retrieval**: Forbidden tiles never loaded into context bundle just to filter later.
