## Summary

This document is a comprehensive, six-phase engineering blueprint for building "Entif v0" — a local-first, sovereign "Second Brain" and autonomous cognitive architecture for Crates McDade's personal venture portfolio. It covers: bare-metal hardware provisioning (Minisforum UM890 Pro), OS hardening (Ubuntu 24.04 LTS, LUKS, BIOS/UEFI), zero-trust networking (Tailscale), PKM (Obsidian/Zettelkasten vault with MCP), a tri-tier memory architecture (Redis/PostgreSQL/Turso+Qdrant+Neo4j GraphRAG), agentic orchestration (n8n + ZeroClaw), the Rosetta 2.0 four-layer meaning protocol and Tripwire governance, Guard-vs-Majordomo dual control, the Coach Module (autonomous self-tuning), the Media & Attention Engine (M1–M6 content flywheel), and the SAFE Inventory MVP. It also encodes the Icosagon Ideology's philosophical mandates as engineering requirements.

## Components And Technologies

- **Hardware:** Minisforum UM890 Pro (AMD Ryzen processor), TPM 2.0, UEFI/Secure Boot
- **OS:** Ubuntu Server 24.04 LTS, LUKS full-disk encryption, LVM
- **Networking:** Tailscale (WireGuard overlay), UFW firewall (tailscale0 only), SSH key-only auth
- **PKM:** Obsidian (plaintext Markdown vault), [[WikiLink]] bidirectional linking, Zettelkasten method
- **MCP Stack:** obsidian-memory-mcp, basic-memory-mcp (npm-compiled), Local REST API plugin
- **Short-term Memory:** Redis (in-memory, RAM-based, volatile; 30–60 min heartbeat)
- **Episodic Memory:** PostgreSQL (Session Key, TTL, Context Window Length parameters)
- **Long-term Memory:** Turso (distributed SQLite edge) OR Qdrant (vector store) + Neo4j (property graph, Cypher queries)
- **Embeddings:** Local Hugging Face models (e.g., nomic-embed) via Ollama (no external API)
- **Orchestration:** n8n (Docker, PostgreSQL backend), webhook ingress, Apple Shortcut (iOS, Apple Neural Engine)
- **Agent Framework:** ZeroClaw (Rust, WASM sandbox, <5MB RAM, <10ms boot), TOML configuration
- **Agent Persona System:** Tulpamancy Synthesis Directive, IDENTITY.md/SOUL.md/AGENTS.md/TOOLS.md
- **Protocol:** Rosetta 2.0 (Layer 0 Signals, Layer 1 Forms, Layer 2 Lexemes, Layer 3 Concepts), Cognitive Tiles
- **Governance:** Tripwire Protocol (zero-memory inference), rosetta.policy (genesis-signed constitution)
- **Dual Control:** Guard (read-only policy enforcer) vs Majordomo (generative agent submitting Capability Envelopes)
- **Self-Tuning:** Coach Module (nightly 4:00 AM ELIXIR loop: receipts, retry policies, routing weights, prompts, alignment)
- **Content Automation:** Media & Attention Engine M1–M6 (simulation mode with HITL gate)
- **Physical Domain:** SAFE Inventory MVP (barcode/QR, photo metadata inference, room glyphs)
- **Semantic Layer:** ELIXIR Framework, Semantic Glyph Engine ("New Ithkuil")

- Tri-tier memory architecture (Redis STM → PostgreSQL episodic → Turso/Qdrant+Neo4j graph) modeled on mammalian retention
- Rosetta Layer 0 observation immutability "mathematically prevents any agent from retroactively altering past inputs"
- ZeroClaw WASM capability model "cryptographically isolates" tool execution, neutralizing prompt injection
- Guard-vs-Majordomo dual control ensures hallucination or logic loops in the generative agent cannot cause physical execution
- Tripwire Protocol "live-time ethical interception" achieves zero-memory external API calls
- ELIXIR Framework + Semantic Glyph Engine produces "hallucination-resistant" and "epistemologically provenance-verifiable" AI reasoning
- Tailscale exit node routes all iPhone internet traffic through the local edge node, enabling true sovereign networking

## Contradictions Or Supersession

- **vs. `docs/RFCs/20260228 - Entif v0 - Spec Proposal - Agentic Messaging.md`:** Agentic Messaging defines GuardLayer as the policy enforcement component for inter-agent messaging with `iam.decision` refs. The Second Brain doc's Guard is a per-session execution guard for the Majordomo agent submitting Capability Envelopes. Both are Guard-named entities with different scopes and protocols. These need architectural reconciliation.
- **vs. OpenClaw Berman PRD (`docs/external/Berman-PRD.md`):** Both documents use the IDENTITY.md/SOUL.md/AGENTS.md/TOOLS.md agent config pattern. The Berman PRD defines a 14-database architecture; the Second Brain doc uses a tri-tier Redis/Postgres/vector architecture. These are different data layer designs that may need reconciliation for shared sub-agents.
- **vs. `docs/external/Entif 2.0 - Enriched by External Advancements - 20251016.md`:** Entif 2.0 Enriched deprecates Ithkuil in favor of WordNet/BabelNet/SyntagNet/VerbAtlas. The Second Brain doc still references "New Ithkuil" as the Semantic Glyph Engine. Direct contradiction on semantic encoding approach.
