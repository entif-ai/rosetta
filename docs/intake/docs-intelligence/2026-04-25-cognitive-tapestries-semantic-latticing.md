## Summary

This PRD synthesizes DeepSeek-OCR's "optical compression" proof-of-concept into a full architectural vision for Entif 2.0, introducing **Semantic Latticing** as the paradigm for moving context compression from the perceptual layer to the conceptual layer. It defines two codec types (Optical and Symbolic), introduces the **Entif Graphemic Core (EGC)** as a machine-native visual language inspired by Ithkuil, and proposes **Swarm Gnosis** as a BitTorrent/blockchain/p2p architecture for distributing Cognitive Tiles. The document also covers ZK-proof-based provenance, thin vertical slices for incremental implementation, and a bio-inspired forgetting mechanism for memory tiers. This is the highest-complexity architectural PRD in the current batch.

## Goals And Intent

- Transform DeepSeek-OCR's vision-text context compression into a core capability ("Optical Cognition") integrated across the Entif nervous system via MCPForge
- Elevate the codec principle from perceptual (DeepSeek-OCR) to conceptual layer via Semantic Latticing
- Replace the "slug" approach with a compositional, deterministic, machine-native visual language (EGC)
- Design Swarm Gnosis: a decentralized, p2p, content-addressed network for Cognitive Tiles with BitTorrent/blockchain/ZK-proof architecture
- Implement a bio-inspired forgetting mechanism (memory tiers 0–3) using optical compression
- Provide thin vertical slices for incremental, risk-managed implementation
- Enable recursive deep parsing via ROMA/DecisionForge with VOI-based information retrieval
- Create verifiable audit trails via ZKP-signed EvidenceBundles

## Components And Technologies

- **DeepSeek-OCR / DeepEncoder**: two-stage architecture (SAM local attention → convolutional compressor 16x → CLIP global attention)
- **MCPForge**: capability governance hub; new verbs optically_compress/optically_decompress; routing criteria compression_ratio/required_precision/is_structured_data
- **FileForge**: pipeline upgrade with optical_extract step; pdftoppm rendering; ExtractedText artifact storage
- **MediaForge / VizForge**: text_to_image rendering via Playwright; ArticleForge layout templates
- **MemoryForge**: memory.lifecycle.workflow ADK workflow; 4-tier forgetting mechanism (Hot/Warm/Cool/Cold)
- **SemanticCodecForge**: central service for slug lifecycle; optical codec (VQ-VAE + DeepSeek-MoE); symbolic codec (GNN + VQ-VAE)
- **WitnessPack / SlugPassport**: immutable proof + canonical representation interfaces
- **DecisionForge / ROMA**: Expected Free Energy calculation; recursive deep parsing VOI loop; multi-pass structured extraction
- **ProvenanceForge**: ZKP-signed EvidenceBundles; compressed image evidence
- **GraphRAG**: upgrade to return SlugURI ranked lists instead of text chunks
- **Swarm Gnosis / Cognitive Tiles**: BitTorrent-inspired p2p network; DHT peer discovery; content-addressed tiles; ZK-proof validation; lightbulb caching hierarchy
- **Entif Graphemic Core (EGC)**: Ithkuil-inspired machine-native visual language; WordNet/BabelNet stems; logical operator modifiers; relation binder operators; fractally-revealing guidebook cipher
- **GNN encoders**: GIN or GAT for graph-to-vector compression
- **VQ-VAE**: Vector Quantization for continuous float to discrete integer code mapping
- **DeepSeek-MoE decoder**: vision token to text decompression
- **ADK (Agent Development Kit)**: workflow engine for memory.lifecycle.workflow

## Conceptual Claims

- **Semantic Latticing elevates the codec principle from perceptual to conceptual layer**: DeepSeek-OCR proved vision-text compression; Semantic Latticing applies the same principle to abstract concepts, compressing argument structures, plans, models, and decisions into addressable slugs
- **Context length is an economic choice, not a token count**: The active context remains small; the perceived context (via vision encoder) spans years. The system decides what to decompress based on cognitive budget and Expected Free Energy
- **Memory follows a bio-inspired forgetting curve via progressive downsampling**: Tier 1 (high-res) → Tier 2 (50% downsample) → Tier 3 (summaries) mimics natural memory degradation; perfect recall degrades naturally
- **Cognitive Tapestries are the compressed artifacts of Semantic Codec Forge**: Complex arguments/models represented as woven lattices of conceptual primitives; nodes are concepts, edges are Semantic Latticing relations
- **EGC is a fractal, compositional machine-native language**: Inspired by Ithkuil; address space scales combinatorially without rainbow-table explosion; guidebook cipher provides deterministic encode/decode
- **Swarm Gnosis is a living, distributed ecosystem for cognitive tiles**: BitTorrent/chunk-splitting inspiration; tiles propagate based on utility; invalid tiles rejected by ZK-proof; prevalent tiles cached aggressively ("lightbulb" caching)
- **Agent thought is an economic decision loop**: Expected Free Energy calculation determines which slugs to decode; cognitive budget allocation replaces passive context loading
- **From intelligence to cognition**: The system no longer merely answers questions based on what it read; it decides what to remember, focus on, and believe—with cryptographic proof at every step

## Contradictions Or Supersession

- **Slug doctrine supersession**: The PRD explicitly evolves the "slug" concept from prior work (OMOC Swarm Gnosis Protocol Spec) into the more structured Semantic Latticing framework. The slug → proof-linked latent → SlugPassport with latent_codes (from VQ-VAE) replaces the simpler slug-as-hash approach. This is a deliberate architectural evolution, not a contradiction.
- **Prior EGC notes in prior extraction**: CT-003 flagged EGC as potentially esoteric/unimplementable. This PRD responds with concrete implementation guidance (WordNet/BabelNet stems, guidebook cipher, fractal revealing), partially addressing the concern but not resolving the combinatorics/esoteric risk fully. EGC remains speculative.
- **Swarm Gnosis architecture matches OMOC spec**: The Cognitive Tiles / Gnostic Atlas / tile-network described here aligns with the OMOC RFC's Swarm Gnosis six-layer model. No contradiction; this PRD provides the product-requirements framing while the OMOC RFC provides the protocol specification.
