## Components And Technologies

- **RosettaCodec tokenizer**: 24k-32k base vocabulary + 1k-4k Rosetta/Ithkuil structural control tokens. Byte fallback or unigram/SPM base. NOT making token IDs the semantic identity — that lives in concept table with RIDs/XID anchors.
- **RosettaEmbed-S**: 100M-150M dual-encoder / bi-encoder. Trained from scratch on English↔Rosetta↔Ithkuil pairs, paraphrases, hard negatives, sense distinctions, graph-neighborhood objectives. Geometry from co-occurrence (node2vec/Laplacian eigenmaps), not random init.
- **RosettaGen-S**: 700M decoder (minimum), 1.3B for useful v1. Architecture: Mamba-3 blocks + periodic CCA attention blocks + Engram-style conditional memory + one depth-routing innovation (mHC preferred over AttnRes for v0).
- **Mamba-3**: State space model for long-sequence state handling and efficiency. 1.8 point accuracy improvement at 1.5B. MIMO variant adds another 1.2 points. Code: state-spaces/mamba.
- **CCA (Compressed Convolutional Attention)**: arXiv 2510.04476. Trims attention compute and KV burden with comparable quality up to 3x faster. Zyphra blog post available.
- **Engram**: DeepSeek paper 2601.07372 "Conditional Memory via Scalable Lookup." O(1) deterministic lookup for static/local patterns. 27B-parameter experiments showing gains in knowledge, reasoning, and context retrieval.
- **AttnRes (Attention Residuals)**: arXiv 2603.15031. Drop-in replacement for transformer depth routing with minimal overhead. MoonshotAI/Kimi work.
- **ReasoningBank**: Google paper 2509.25140. Strategy-level agent memory framework for test-time self-evolution via reasoning memory.
- **TurboQuant**: turbo-quant.com. Near-optimal KV cache / vector compression. Quality-neutral at 3.5 bits/channel. Use post-stability only.
- **MegaTrain**: arXiv 2604.05091. Full precision 100B+ training on single H200 using host memory as authoritative parameter store.
- **Draft-and-Prune (D&P)**: arXiv 2603.17233. Improves auto-formalization reliability on AR-LSAT and logic benchmarks. Use as evaluator/scaffold, not base architecture.
- **H-Neurons**: xsingular.com. Sparse circuitry analysis for hallucination diagnostics. Use post-training, not inside core.
- **ZeroSearch**: Alibaba-NLP. Simulated search rewards for search RL training without live search API costs.
- **Recursive Language Models (RLMs)**: arXiv 2512.24601. Long-context via test-time unrolling rather than brute-force context stuffing.
- **Tiny Recursive Models (TRM)**: Samsung Montreal. 7M model surpassing DeepSeek-R1 on ARC-AGI. arXiv 2510.04871.
- **HRM**: Hierarchical Reasoning Model — narrow structural task specialist, surprisingly small and strong on puzzle reasoning.
- **INTELLECT-2**: Decentralized RL training model. Relevant to swarm compute vision later.
- **DeepCrossAttention**: Fallback residual family contender if mHC/AttnRes disappoint.
- **GLoVe-V + MFT**: Updated lexical embeddings as cheap cold-start for embedder and memory tables.
- **Continuous Thought Machines**: arXiv 2505.05522 — too speculative for first falsifiable build.
- **Nested Learning**: Google Research — too speculative for first falsifiable build.
- **Darwin/Huxley Gödel Machines**: Self-improving agent research — above base model, not inside it.

## Conceptual Claims

- Token IDs are arbitrary handles within each tokenizer; semantic identity lives in a separate concept table with opaque RIDs and XID anchors; embedding geometry lives in concept prototypes, not in integer ID adjacency
- The cheapest viable path is NOT one glorious everything-model but a three-artifact Rosetta-aware triad (tokenizer, embedder, decoder) with controlled ablations
- Below 700M parameters, the model is a semantic scalpel, not a general assistant — frame success as semantic normalization + reasoning, not general capability
- Every added architectural primitive must earn its calories through explicit ablation; glitter-bomb models are not falsifiable
- Ithkuil is a curriculum engine that orders distinctions — not a sovereign ontology to be embedded as-is
- Engram's O(1) memory plane enables deterministic offload of static patterns, directly relevant to Rosetta's memory planes and tapestries
- Mamba-3 + CCA hybrid addresses long-sequence state tracking AND KV compression simultaneously
- LoRA cannot validate a custom tokenizer; it can only test curriculum and loop logic on models with fixed tokenizers
- Cost floor is in the hundreds of dollars; realistic budget is 5x-10x due to failed runs, data curation, synthetic pair generation, and evaluation overhead
- Semantic gains must be proven against iso-parameter AND iso-FLOPs baselines, not just against random initialization

## Dependencies And Sequencing

- **Prerequisite**: Evaluation harness must be built BEFORE training begins (4-6 weeks allocated)
- **Phase 0 (Risk probe, $2k-$10k)**: Tokenizer/codec + LoRA bundle-reading tests on existing open model. Tests tokenizer validity without full retrain cost.
- **Phase 1 (Minimal v0, $10k-$35k)**: Tokenizer + 100-150M embedder + 700M generator + one depth-routing ablation + eval harness. First falsifiable scratch experiment.
- **Phase 2 (Useful v1, $25k-$75k)**: Tokenizer + 150-250M embedder + 1.3B generator + 3-5 ablations + external reasoning memory. Gated on Phase 1 round-trip metrics showing lift.
- **Phase 3 (Serious foundation, $100k-$300k)**: 1.3B-3B family, multiple seeds, full diagnostics, search/RL sidecars, serving/quantization. Gated on Phase 2 metrics.
- **Defer**: TurboQuant (post-stability), MegaTrain (>1B only), INTELLECT-2 (swarm compute vision later), Continuous Thought Machines, Nested Learning, Darwin/Huxley Gödel Machines
- **Embedder init dependency**: node2vec/Laplacian eigenmap graph must be constructed from co-occurrence data before embedder training begins
