## Summary

This addendum defines the **Source Substrate** as a new first-class constitutional protocol domain for Rosetta/Entif. It establishes a multi-object source model (artifact identity, manifestation, acquisition event, custody context, publication context, identifier bindings, authorship claims, identity evidence, stewardship posture, rights context, lifecycle events, trust analysis) that must replace the single flat source field pattern. It introduces a 9-facet orthogonal classification model, an 8-dimension multi-provenance lattice, a 15-axis trust-as-vector model, a 4-layer deduplication strategy, and 11 proposed pack suites. It also defines identity-sensitive escalation thresholds that trigger the stronger governance path when stylometric or behavioral fingerprinting is detected.

## Goals And Intent

- Establish Source Substrate as a distinct constitutional domain
- Prevent collapse of multiple distinct source roles into single identifier fields
- Preserve external authority bindings without Rosetta-native replacement
- Enable trust as a multi-dimensional vector, not a scalar score
- Define explicit ingestion, retrieval, and evaluation workflows for external sources
- Provide a source priority tier model for sequencing ingestion complexity
