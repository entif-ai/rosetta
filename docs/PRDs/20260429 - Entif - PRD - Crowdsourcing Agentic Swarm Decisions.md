**R-002 MCP contract surface.** Confirm current MCP tools/resources/prompts schema, transport options, auth posture, and server template strategy. **R-003 Policy engine progression.** Compare JSON policy v0, OPA/Rego v1, Cedar, and Zanzibar-style auth for later enterprise use. Output: policy adapter interface and OPA migration ADR. OPA’s value is unified policy-as-code across the stack, but it does not need to be first-day plumbing. ([Open Policy Agent](https://www.openpolicyagent.org/docs?utm_source=chatgpt.com))

**R-004 Supply-chain attestation.** Map SLSA, Sigstore, in-toto, CycloneDX, npm provenance, and GitHub OIDC into SkillPack releases. Output: `entif-supply-chain` roadmap. **R-005 Privacy-preserving swarm telemetry.** Evaluate OpenDP, RAPPOR-style randomized response, PySyft-style remote execution, aggregation thresholds, and contribution caps.
