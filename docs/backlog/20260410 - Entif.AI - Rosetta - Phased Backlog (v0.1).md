## 0. Read this first

This backlog is not a wish list.  
It is the operational staircase for building the Rosetta/Entif system under solo-builder realism.

### Governing rules
1. **Thin vertical slices beat majestic fogbanks.**
2. **Every meaningful step emits receipts.**
3. **Raw signals never get overwritten by interpretations.**
4. **Cheap-first refinement happens before expensive semantic hydration.**
5. **Parse-only default remains the safety baseline.**
6. **Tests are the backlog’s executable skeleton.**
7. **Anything deferred should exist as a failing test, stub, or explicit non-goal rather than hand-wavy absence.**

### Effort model
- **XS** = under 4 hours
- **S** = 1 micro-tier (4 hours)
- **M** = 2-3 micro-tiers
- **L** = 1-2 days
- **XL** = multi-sprint / explicitly not immediate

### Priority model
- **P0** = blocker / constitutional
- **P1** = required for next rung
- **P2** = strengthens current rung, not blocking first proof
- **P3** = valid later or specialist lane
- **P4+** = intentionally deferred

### Merge policy
- `tests/unit`, `tests/integration`, `tests/conformance`, and required schema checks are merge-blocking
- `tests/backlog` are allowed red if explicitly tagged as backlog-only and excluded from release-critical gates
- no known-red tests are allowed in the core packages of the current rung once that rung is declared green
