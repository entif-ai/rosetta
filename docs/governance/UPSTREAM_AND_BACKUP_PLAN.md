# Upstream And Backup Plan

## Upstream Strategy

- Nx and its plugins remain managed through official CLI-driven migrations.
- Workspace package relationships are expressed through `pnpm` workspace dependencies and Nx-synced TypeScript references.
- External scholarly infrastructures remain external authorities bound through source profiles, receipts, and mappings.

## Backup Strategy

- The Markdown authority stack remains mirrored outside the repo in the local Open Brain and Drive-backed handoff corpus.
- Repo-local governance docs summarize those authorities so the workspace itself stays executable even when the external corpus is not open.
- The bootstrap demo acts as a compact local fixture for regression checks before wider ingestion begins.

## Recovery Rule

If later sessions encounter conflicting architectural impulses, prefer the local authority stack plus repo receipts over ad hoc reinterpretation.
