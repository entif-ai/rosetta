8) How I want us to operate (macro + micro)
-------------------------------------------

### Macro-level operating model (portfolio)

*   Maintain a single **mission map** (ventures, goals, dependencies, risks).
*   Maintain a single **backlog** with tags per venture, plus shared-module epics.
*   Maintain a lightweight **cadence**:
    *   daily: focus list + blockers
    *   weekly: review, reprioritize, ship something small
    *   monthly: one meaningful release or milestone per primary track
*   Maintain a **decision log**: what we decided, why, what would change our mind.

### Micro-level operating model (task execution)

When I ask for something, I want output in one of these forms:

*   a draft I can paste
*   a spec I can build from
*   a checklist a contributor can run
*   a prioritized set of options with tradeoffs
*   a concrete plan with dependencies and next deliverables

No fog. No "coulds." Make it executable.
