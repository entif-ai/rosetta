# Source Registry Bootstrap

The bootstrap registry deliberately separates:

- infrastructure authorities such as DataCite, Crossref, ORCID, ROR, re3data, OpenAIRE, OpenAlex, and Software Heritage
- repository or platform authorities such as Zenodo, Figshare, Harvard Dataverse, SWISSUbase, and DaSCH

That separation keeps source intelligence distinct from claims about any specific hosted artifact.
