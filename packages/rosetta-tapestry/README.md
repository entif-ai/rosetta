# rosetta-tapestry

## Purpose

Compiles a receipt bundle into a tapestry tile that packages subject, evidence, and policy closure.

## Working Today

- produces tapestry tiles from receipt, subject, evidence, and policy CIDs
- records stable prefix, dynamic tail, required scope, and a simple token estimate

## Fixture Status

- executable
- currently used as packaging metadata inside the bootstrap flow

## Not Yet

- graph traversal
- retrieval planning
- optimization based on real corpus structure

## Roadmap

- grow the tapestry concept into a more powerful query and evidence-packaging primitive
